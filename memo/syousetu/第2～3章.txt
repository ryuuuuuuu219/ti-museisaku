◇◇事実
Janthinobacterium lividum（ヤンチノバクテリウム・リビドゥム）
は紫色の色素 ビオラセイン（violacein） を産生します。そして実際にサンショウウオなど両生類の皮膚から分離されており、単なる「皮膚についている菌」ではなく、宿主に利益を与える共生関係の候補として研究されています。
ビオラセインなどの代謝産物が抗真菌作用を担います。

◇◇モンスター娘としての落とし込み
この獣人種では近縁の共生菌が表皮上に定着しており、菌同士の競争によって一定の分布域を形成する。共生菌が産生する紫色色素と宿主自身の皮膚色との組み合わせによって、個体ごとに特徴的な斑紋が現れる。

共生菌の増殖状態や色素産生量は宿主の栄養状態、皮膚環境、免疫状態などによって変動するため、斑紋の彩度やコントラストは経験的に健康状態の指標として認識されるようになった。

やがて鮮明な斑紋が健康な個体のシグナルとして求愛にも利用されるようになり、宿主側では共生菌に適した皮膚環境を維持する形質が、菌側ではより安定して鮮明な色素を産生する株が選択されていった。

モデルはブラキディオスにでもする？

種族名は（紫系統色・二藍）フタアイあたり？

◇◇事件シナリオ
美容の悩みとして思春期のフタアイ少女が来院する
学校生活などのストレスでメンタル不調、体調を崩し気味で不登校。
本人はいじめにあっている自覚がある。

主訴はメンタル不調と容姿への不安

事件シナリオは、因果関係を一段整理するとさらに強くなります。

まず学校でいじめを受ける。そこに単なる悪口や孤立だけでなく、弱い呪いを継続的に付与されるという異世界特有の加害がある。呪いによって睡眠や食欲などが乱れ、身体的ストレスが続く。その結果、皮膚環境も変化し、フタアイ固有の共生菌が減少する。共生菌が減ったことで紫色の斑紋が薄くなり、本人は「自分は醜くなった」「体調まで悪くなっている」とさらに不安になる。

つまり、

いじめ → 呪い → 全身状態の悪化 → 共生菌叢の変化 → 斑紋の退色 → 容姿不安 → さらなるストレス

という悪循環です。

ここで大事なのは、「メンタルケアが間違い」にはしないことですね。本人は実際にいじめを受けているので、カウンセリング自体は必要です。ただし、それだけでは身体症状の原因を除去できない、というミスリードにすると医療として自然です。

抗生物質はもっと分かりやすい悪手になります。「皮膚に大量の細菌がいる」というスキャン結果だけ見て感染症と判断し、抗菌処置をすると、病原菌だけでなく保護的な共生菌まで減らしてしまう。結果、色がさらに薄くなり、真菌などの侵入リスクまで上がる。

診断部分も、「細菌叢を発見する」だけだと一発で答えが出てしまうので、ゲームにするなら段階を作ったほうが面白いです。

たとえば、

スキャン魔法 → 表皮に大量の微生物反応を確認 → 毒性解析では有害物質がほぼ出ない → 健康な皮膚と退色部を比較 → 紫色部に特定菌が多い → 培養すると病原菌・真菌に対する生育阻止円を確認

という流れにできます。

最終的な正解も一つではなく、

呪い解除 ＋ 共生菌を温存・回復させる処置 ＋ 本人への心理的支援

の三本立てになります。

この症例でかなり面白いのは、「呪い解除をしたら即完治」ではないところです。呪いは原因の上流ですが、一度崩れた菌叢はその場では戻らない。だから呪い解除後も斑紋は薄いままで、数日～数週間かけて戻る設定にできます。

そうすると患者が「治ってない……色が戻らない」と不安になるところで、医者側が、

「原因は除いた。ただ、君の身体に暮らしている彼らが戻るには時間がいる」

みたいに説明する場面も作れます。

そしてこの症例、ステージとしてかなり良いのが、「呪い」「精神状態」「美容」「微生物」という一見別々の情報が、最後には一つの因果鎖になることです。ステージ1より一段複雑な症例としてちょうどよさそうです。

◇◇ミスリード
メンタルケア・カウンセリングのみでは不十分
抗生物質の処方は悪手

◇◇正解の診断
いじめとは呪いの付与すら行われている→呪い解除
スキャン魔法によって細菌叢を発見すること
カウンセリング、加害者の話を聞く→第3章へ

◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇◇

「脳腫瘍になると判断力が落ちて加害行動をする」と一般化するのは強すぎます。腫瘍の位置や周囲への圧迫によって、前頭葉系の機能が障害されれば、抑制低下、性格変化、判断力・計画性の低下などが起こり得る、くらいにすると自然です。つまり鹿人少女については、もともとの人間関係上の問題に、脳腫瘍による行動変化が重なっているという形がよさそうです。

設定としては、こんなふうにつながります。

被害側のフタアイ少女は、「いじめられている」「呪いまで掛けられている」「斑紋が薄くなってきた」という主訴で来院する。診察すると実際に呪いが存在し、それによるストレスや体調悪化を介して共生菌叢が崩れ、斑紋の退色も起きている。したがって被害そのものは思い込みではない。

ところが調査すると、呪いを付与していた鹿人少女にも最近になって異常があり、以前より攻撃的・衝動的になった、授業中に不可解な判断をする、頭痛や吐き気など別の症状もある。そこで鹿人少女を診察すると、頭部スキャンで腫瘤が見つかる。

そしてここで、以前考えていた「鹿の角と癌」をそのまま重ねられます。

最初は、

「性格変化＋頭部腫瘤 → 脳腫瘍」

と考える。

しかし詳しく見ると、腫瘤そのものは悪性腫瘍ではなく、皮下から成長している角組織だった。ただし角の成長方向が異常で、周辺組織を圧迫して神経症状を起こしている、という形にすれば両方のネタが生きます。

つまり、

鹿人少女の異常角形成 → 頭蓋・神経系への圧迫 → 行動変化
→ フタアイ少女へのいじめ・呪い
→ ストレスと呪いによる体調悪化
→ 共生菌叢の破綻 → 斑紋退色

という一本の因果鎖になります。

これ、ゲームとしても面白いです。最初に提示される患者はフタアイ少女なので、プレイヤーは「いじめられた少女を治療する話」だと思う。しかし治療を進めても、加害者からの呪いが再付与される限り根治しない。そこで原因を追跡すると加害者へ行き着き、今度はその加害者自身が第二の患者になる。

さらに「鹿人少女も病気だった」からといって、いじめという行為まで無かったことにしない方がいいです。

医学的原因の発見と、

「加害行為への責任や被害者へのケア」

は別問題として残す。

そうするとかなり深みが出ます。病気による行動変化があったとしても、フタアイ少女が傷ついた事実は消えない。一方で鹿人少女を「悪人だから倒す」だけでも済まない。この作品の「診断して治療する」というテーマにもかなり合っています。

そして症例として整理すると、実はかなり綺麗な二段構成です。

症例A：フタアイ少女
主訴：不登校、気分不調、容姿不安、斑紋の退色
真因：呪い＋ストレス → 共生菌叢の乱れ
治療：呪い解除、菌叢回復、心理的支援

症例B：鹿人少女
周囲からの訴え：最近性格がおかしい、攻撃的、呪術を乱用する
症状：頭痛など＋行動変化
ミスリード：悪性脳腫瘍
真因：異常方向へ成長した角組織による圧迫
治療：成長方向と血管走行をスキャンし、角組織を適切に処置する

こうすると、もともと別々だった「菌共生」と「鹿の角」を、一つの事件の被害者と加害者として自然に統合できます。

個人的には、この症例は「脳腫瘍罹患」そのものより、脳腫瘍だと思わせて実は異常角形成だった方が、最初に考えていた鹿人ネタを最大限活かせます。
