総合検査　生体値時間変化関数
==============================

目的
----
総合検査中のMPを疑似的な経過時間として扱い、ステージごとの心拍数、苦痛度基準値、苦痛度ばらつきの変化を指定する。


共通規則
--------
- 入力値は現在MPとする。
- MPは検査開始、検査魔法切り替え、検査中の時間経過によって減少する。
- ゲーム中は、MPの高い側から低い側へ関数をたどる。
- 各関数は、複数の`MP, 出力値`の制御点で指定する。
- 制御点と制御点の間は、指定された補間方法で計算する。
- 制御点より高いMPまたは低いMPでは、最も近い端の値を維持する。
- MPの制御点は、高い値から低い値の順に記載する。

補間方法は次のいずれかを指定する。

- Linear：制御点間を直線で補間する。
- Smooth：制御点間を滑らかな曲線で補間する。
- Step：次の制御点へ到達した瞬間に値を切り替える。


使用する関数
------------

MP 0ポリシーはステージごとに次の2種類から指定する。

- Stable：MPが0になっても、心拍数、苦痛度基準値、苦痛度ばらつきは各関数の`f(0)`を維持する。
- Fatal：MPが0になった瞬間、心拍数を0、苦痛度をN/A、苦痛度ばらつきを0とする。苦痛グラフは非表示にする。

1. 心拍数

```
心拍数 = heartRateByMp(MP)
```

- 単位はbpm。
- 0未満の値は0として扱う。
- 心拍グラフのサンプリング間隔にも使用する。

```
心拍サンプリング間隔（秒） = 60 ÷ 心拍数 ÷ 8
```

- 心拍グラフは1拍を`10, -3, 1, 0, 0, 0, 0, 0`の8サンプルで表す。
- リングバッファの配列長は80で固定し、約10拍分を保持する。
- 心拍グラフと苦痛グラフのLineRenderer線幅は0.2とする。
- 心拍数が0の場合は、心拍グラフへ0だけを記録する。


2. 苦痛度基準値

```
苦痛度基準値 = painLevelByMp(MP)
```

- 値の範囲は0～10。
- 0未満は0、10を超える値は10として扱う。
- 苦痛グラフの中心となる値を表す。


3. 苦痛度ばらつき

```
苦痛度ばらつき = painVariationByMp(MP)
```

- 値の範囲は0～10。
- 0未満は0、10を超える値は10として扱う。
- 苦痛グラフの上下方向の最大振幅を表す。


4. グラフへ記録する瞬間苦痛度

```
苦痛波形 = sin(時間 × 2.2) × 0.65
          + sin(時間 × 2.2 × 0.37) × 0.35

瞬間苦痛度 = 苦痛度基準値
             + 苦痛波形 × 苦痛度ばらつき
```

- 苦痛波形は、おおむね-1～1の範囲で変化する。
- 瞬間苦痛度は、おおむね`基準値－ばらつき`から`基準値＋ばらつき`の範囲で変化する。
- 苦痛グラフの記録間隔は0.15秒で固定する。
- 現在、苦痛波形そのものの周期はMPへ連動しない。


ステージ記入書式
----------------
次の書式をステージごとに複製して使用する。

```
[StageXX]
stage = ステージ番号
mpZeroPolicy = Stable / Fatal

heartRateByMp
interpolation = Linear / Smooth / Step
points =
MP, bpm
MP, bpm

painLevelByMp
interpolation = Linear / Smooth / Step
points =
MP, 苦痛度基準値
MP, 苦痛度基準値

painVariationByMp
interpolation = Linear / Smooth / Step
points =
MP, 苦痛度ばらつき
MP, 苦痛度ばらつき

備考 = 病状変化の意図やイベントとの関係
```


Stage01　時間変化関数
--------------------
MPの低下に伴って、心拍数、苦痛度基準値、苦痛度ばらつきが直線的に上昇する。

```
[Stage01]
stage = 0
mpZeroPolicy = Fatal

heartRateByMp
interpolation = Linear
points =
100, 88
0,   130

painLevelByMp
interpolation = Linear
points =
100, 5
0,   8

painVariationByMp
interpolation = Linear
points =
100, 0.5
0,   2

備考 = MP100からMP0へ進行するにつれて症状が悪化し、MP0でFatal状態へ移行する。
```


設計時の注意
------------
- 検査開始時の20 MP消費後のMPから表示が始まる。
- 検査魔法切り替え時の2 MP消費も、疑似時間の進行として各関数へ反映される。
- 目視・非破壊内部検査中は毎秒0.1 MP、読心中は毎秒1 MPを消費する。
- MPは実時間そのものではない。時間経過消費だけでMPが減る場合、`MP差10`は目視・非破壊内部検査では100秒、読心では10秒に相当する。
- 魔法切り替えを行うと、実時間を待たずにMPと病状表示が先へ進む。
- 急変を表す場合はStep、徐々に悪化または回復する場合はLinearまたはSmoothを使用する。
- 実装へ反映する際は、各ステージの`ExaminationStageVitalsData`に同じ制御点を設定する。
